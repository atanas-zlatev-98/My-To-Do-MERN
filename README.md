Project: MERN Stack TODO Application

##[Technologies]: MongoDB, Express.js, React.js, Node.js, JavaScript, HTML, CSS

Designed and developed a full-stack TODO application using the MERN stack with all code written independently.

Built a responsive and interactive front-end using React, focusing on clean UI and smooth user experience (No mobile view).

Implemented core task management features including creating, editing, deleting, and displaying tasks (CRUD).

Integrated the front-end with a Node.js and Express.js backend to handle API requests and data flow.

Used MongoDB for storing and managing task data.

[NOTE]: The project has low to none validation!!!
